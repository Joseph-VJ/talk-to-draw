# 🚀 How to Run TalkDraw


### Step 1: Start Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

✅ Backend running at: **http://localhost:5000**

---

### Step 2: Start Frontend

Open a **new terminal**:

```bash
cd frontend
npm install
npm run dev
```

✅ Frontend running at: **http://localhost:5173**

---

## Open the App

🌐 Go to: **http://localhost:5173/**

---

## How to Use

1. **Type** a prompt like "a cute cat" OR click **🎙️ mic** to speak
2. Click **✨ Draw** button
3. Watch the AI draw your image!
4. View all drawings in **Gallery**

---

## Stop the App

- Press `Ctrl + C` in both terminals

---

**Happy Drawing! 🎨**
